# 背包、武器编辑与一键解锁（2026-11-25）

## 一键解锁

助手的「账号与启动」页提供「一键解锁可用内容并保存重启」。在线时先取得当前账号最新快照并备份、保存退出，按当前配置写入解锁记录，再启动游戏。重复执行不会重复发放奖励；不会替换队伍、战斗装备或已保存的时装颜色。

当前配置覆盖：

- 73 个具有动画资源的拍照动作，包含应援、宕机、怎么搞的、吃瓜和威胁。
- 67 项星云树能力的最高配置等级，以及对应解锁物品和能力奖励。
- 每个角色的采集手套、伐木斧、挖矿锤、捕虫网、水壶、鱼竿、载具及铲子工具槽。只补空槽或无效引用，保留原先有效的工具；没有相应实例时发放一个有效配置的工具。
- 38 棵祈愿树的 515 个配置节点。
- 867 个主线、支线、外传等配置任务，11 张本地地图、73 个区域、3966 项永久收集和176个宝箱记录。
- 已拥有服装的有效染色方案，保留现有颜色。

「需要在樱庭世界星云树解锁挖矿锤」有两层原因：服务端此前返回空能力列表，角色外观记录中的采集工具槽也为零。工具只存在于背包时，客户端仍会判定不能使用。现在同时保存能力等级和有效工具实例引用，并在登录时同步动作和能力状态。

一键解锁用于当前客户端及本地服已支持的内容。刷新型采集物保留正常刷新；限时活动流程、多人交互参与者和缺失资源不由此按钮生成。它会完成剧情记录，想正常推进剧情时请只用下方的分项按钮。

## 武器编辑

进入「武器编辑」，搜索名称或 ID，并按实例编号选择一把武器。可修改等级、基础攻击力、暴击率、平衡性和强化等级。同名武器互不影响。

等级与强化范围来自该武器的真实配置。攻击力使用非负整数，百分比最多两位小数。基础攻击不包含强化加成；例如基础攻击 123456、强化加成 1086，游戏显示总攻击 124542。「恢复配置属性」清除攻击、暴击和平衡性的自定义覆盖，保留等级与强化；「还原本次输入」仅撤销尚未保存的输入。

目标数值单独持久化为 localStats，原始随机参数保留。在线编辑在游戏服务端主循环验证并等待 SQLite 完成，再同步客户端；离线编辑只更新目标账号。客户端会在背包模型就绪后重建该实例的计算字段，并在属性更新完成后重新应用覆盖。原始对象身份与穿戴引用保持不变。

若该实例在游戏里发生变化，旧编辑会被拒绝，草稿输入保留。每次保存前自动备份。已装备武器请重新装备以刷新战斗派生属性；本轮已实测未穿戴武器的面板数值、重启保留和恢复，未把所有战斗伤害公式列为通过。

## 背包装备修复

旧预设把藏宝图 5070001、5070002 当作普通堆叠物品发送，而客户端要求专用实例，造成分类枚举遇到空对象。部分装备还缺少图标，防具主属性固定为零。

迁移将两种错误藏宝图、177件不完整防具和25件不完整武器保留到 localInventoryArchive；3件已穿戴占位防具换成同系、同部位、同品质的可用配置，保留实例和穿戴引用。423件可用防具按配置补齐主属性。旧对象仍在归档中，未直接丢弃。

当前实际账号库存为 653 件武器、423 件防具、9152 种基础资源。数量变少的部分来自隔离不完整条目，不代表已验证每个物品都能完成所有相关玩法。

# 速度异常修复与实时属性（2026-11-25）

这次异常由全资源预设把永久能力道具也发放了 9,999,999 份引起。客户端按数量叠加能力加成，导致移动、攻击、生命等属性溢出到异常量级。

## 现场证据与修复

- 修改前 Unity 时间倍率为 **1**，因此这次异常不是时间倍率残留。
- 角色基础移动速度为 4.5，能力叠加的移动加成为 999,999.875，最终移动速度为 **1,000,004.375**。
- 两个移动能力道具 110001011、110001013 的单份配置各为 0.05，但存档数量各为 9,999,999。
- 修改前角色坐标约为 (20633, 14032, -15082)。修复并重新登录后回到正常场景，画面恢复；移动速度为 **4.6**，即 4.5 + 0.05 + 0.05。
- 能力、功能解锁和外观登记按永久拥有处理，数量上限为 1。重复预设、单项发放和在线 change_item 都遵循该规则。
- 旧存档修复只归一化这些永久条目的数量，不删除角色、皮肤、装备或普通资源。助手在离线启动前执行同一迁移；编辑存档前自动备份。

上述数字来自速度异常修复时的历史快照。当前资源完整角色数为27，旧账号已有条目保留；资源和装备数量以助手实时面板为准。

## 使用实时属性

双击「开放空间单机助手.exe」，进入游戏场景后选择左侧「实时属性」。默认勾选「调整后自动应用」；滑块停止拖动约250毫秒后提交，数字输入确认或离开输入框后提交。也可以取消自动应用，逐项点击「应用」。实际值每秒读取一次。

| 功能 | 可设置范围 |
| --- | --- |
| 全局时间倍率 | 0.1–5；正常为1 |
| 当前生命 | 1–当前最大生命，或点击恢复满血 |
| 移动速度 | 0.1–30；本账号正常值4.6 |
| 攻击力 | 0–10,000,000 |
| 防御力 | 0–1,000,000 |
| 最大生命 | 1–100,000,000 |
| 跳跃速度 | 0–50 |
| 暴击率读值 | 0–1 |
| 暴击伤害倍率 | 1–20 |

「默认」恢复当前角色、装备、能力计算出的属性；「全部恢复默认 / 正常速度」清除所有属性覆盖，并将全局时间倍率设为1。降低生命上限或恢复默认时，会把超出的当前生命同步限制到新的上限。

实时覆盖仅存在于当前游戏进程，不写入账号数据库，退出游戏后消失。属性覆盖在每次读取时重新识别当前主控角色的属性对象；不会把此前角色的地址留给下一场景使用。全局时间倍率影响整个游戏；本版本没有单独调整攻击动作播放速度的控件。

## 实现与验证范围

- 托管读取和生命设置在 Unity 主线程队列中执行。
- 原生属性入口使用动态解析的方法和字段偏移，仅对当前主控角色返回覆盖值；保留原计算函数用于默认值及恢复。
- 已验证9项控件的实际读回、单项和全部恢复、生命上限校正、非法批量请求不产生部分修改、数字输入与滑块自动提交。
- 独立诊断读取确认：主控角色的值改变，场景内另外16个单位保持原值。
- 已验证重启清除临时覆盖，正常速度、能力数量和全收集存档保持。启动器117项与存档9项回归通过。
- 切换队伍的自动化尝试没有使当前主城角色实例立即重建，故不将该尝试列为跨角色/跨场景实测通过。所有地图、所有战斗公式仍未逐一覆盖。
- 测试及证据保存在安装目录的「验证」子目录；公开源码包只包含代码和验证说明。

# 配置、账号与保存

本地 UID 账号不需要官方密码。助手在独立 profile 上工作，在线变更通过游戏协议或服务端主循环完成；离线编辑先保存退出并备份。不要在客户端运行时直接修改 SQLite 或用旧整库覆盖近期进度。

全收集依据 Steam 实际配置及资源完整性判断：当前 27 个完整角色、541 个皮肤条目。补齐莉和朱寅；旧存档已经持有的其他条目保留。因此旧存档角色计数可能是 28，与新建预设的 27 个有效角色并不矛盾。

普通资源可大量发放，永久能力/解锁条目固定保留一份。角色等级、星级和技能受各自配置约束。装备和武器创建真实实例，不能简单把基础背包数量设置为巨大值代替。

头像、映像、宠物、皮肤的配置存在不等于全部内容逐一实机测试。缺模型、技能或基础武器的角色不对新预设发放。

更新 Steam 资源后重新导出并验证服务端表，步骤见 `Steam更新与卡池.md`。源码包不附带已准备的个人账号；实际存档和备份只留在本机。

本轮新增「武器编辑」和「一键解锁可用内容并保存重启」，并修复背包、装备和采集工具槽。使用方式、迁移范围与实测限制见 [背包装备与一键解锁](背包装备与一键解锁.md)。

# 开放空间 Steam 单机修复与管理

基于 miaomiao-launcher 与 Lolo 26.5 的本地修复源码包，包含上游补丁、新增代码、中文助手和构建安装脚本。源码包用于本地构建、检查与 GitHub 发布。

## 助手功能

- 本地 UID 登录、自动进入场景、独立存档、在线快照备份与恢复。
- 账号等级和资料、资源发放、可用全角色与全皮肤预设、角色等级/星级/技能、队伍、世界等级。
- 保存剧情任务完成记录、本地地图与区域开放、永久收集登记；操作前备份，在线时保存退出后应用并重新启动。
- 实时修改主控角色的移动、攻击、防御、生命、跳跃、暴击及全局倍率，支持恢复默认。永久能力道具不再重复堆叠，避免全资源预设造成异常速度。
- 读取客户端实际注册的 124 条 GM 指令，区分本地服支持和未实现的部分；原生 GM 窗口入口属于实验功能。

当前资源完整的角色为 27 个，皮肤配置 541 件。旧存档已拥有的其他角色会保留，不会因目录过滤而被删除。缺少主模型的乌、宁不纳入新发放和常驻卡池。不能将“数据库中存在条目”当作模型、技能、地图和所有官方后台功能均已实现。

## 源码与构建

`upstream.json` 记录上游提交、修改文件和支持的 GameAssembly 哈希。此包不包含游戏客户端、游戏资源表、账号存档、密钥、日志、工具链或预编译程序。

需要 Windows x64、官方 GitHub CLI `gh`、Git、Go 1.26.2 和 Windows .NET Framework C# 编译器：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\Build-Local.ps1 -WorkRoot .\build
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\Install-Local.ps1 -BundleRoot .\build\output -PortableRoot "<现有 OverFieldLauncher-portable 绝对路径>"
```

构建脚本通过 `gh repo clone` 获取固定上游、应用补丁并编译；重复构建需要新的 WorkRoot。安装前保存退出本地游戏和助手，安装器会备份被覆盖文件。现有便携包仍需提供 Python、Frida、游戏资源和数据库结构。

更新资源、导出配置与生成常驻池见 `docs/Steam更新与卡池.md`，存档与账号见 `docs/配置与账号.md`，剧情及换装见 `docs/剧情地图与时装修复.md`，验证范围见 `docs/验证记录.md`。

## GitHub 发布

先检查源码、补丁和 `FILE-MANIFEST.json`。发布脚本在检查源码并明确决定发布后执行，通过官方 `gh auth`、`gh repo create --source --push` 完成认证、建库和由 gh 调用 Git 推送。不会因构建或安装自动发布。使用官方 CLI 本身不代表 GitHub 风控结果的保证。
